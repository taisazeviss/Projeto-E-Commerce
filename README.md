# E-Commerce - VS Code

Projeto VS Code em PHP para consumir banco de dados criado no curso de SQL.

## Tecnologias Utilizadas

* **PHP** (Manipulação e lógica do sistema)
* **MySQL Workbench 6.3 CE**
* **XAMPP** (Servidor web Apache e banco de dados local)
* **VS Code** (Editor de código)

## Estrutura do Projeto

```text
.
├── css/             # Arquivos de estilização da aplicação
├── DAO/             # Data Access Object (Comunicação com o banco de dados)
├── DataBase/        # Scripts SQL de criação e povoamento do banco
├── editar.php       # Página de edição de registros
├── excluir.php      # Lógica de exclusão de registros
└── index.php        # Página inicial e listagem de produtos
